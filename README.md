# 🐍 Python Hosting on Vercel

منصة متكاملة لتشغيل كود Python مباشرة في المتصفح مع دعم المكتبات الشائعة.

## ✨ المميزات

- ✅ تشغيل كود Python مباشرة
- 📦 دعم numpy, pandas, requests, matplotlib, scipy, sklearn
- 📁 رفع ملفات .py وتنفيذها
- 🎨 واجهة مستخدم عربية مريحة
- ⚡ أداء سريع على Vercel
- 🔒 بيئة آمنة ومعزولة

## 🚀 النشر على Vercel

1. رفع الملفات إلى GitHub
2. تسجيل الدخول إلى [Vercel](https://vercel.com)
3. استيراد المشروع من GitHub
4. النشر التلقائي

## 📦 المكتبات المدعومة

- numpy, pandas, scipy
- requests, beautifulsoup4
- matplotlib, pillow
- sympy, scikit-learn
